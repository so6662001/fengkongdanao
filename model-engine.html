新增特征说明
① 失信检测 API 实时风险事件
大模型同时解读风险事件严重等级，区分不同风险量级 —— 这一步决定了风险上调幅度：
事件类型大模型判定概率增量
小额买卖合同纠纷（<50万）小额官司+3~6%
劳动仲裁若干起小额纠纷+2~5%
工程款纠纷（数百万）传导型风险+10~16%
经营异常 / 股权冻结股东层风险+12~20%
大额被执行 / 账户冻结资金链断裂+20~30%
关联方大额失信风险传导+8~15%
② 辅助维度：客户在平台的挂牌行为
如果下游客户本身也在自有资源平台开店，可同步观察其挂牌行为变化 —— 突然大量抛售自有货物，往往也是资金紧张信号，作为隐性风险特征。
宏基建设集团（既是赊销客户又是平台商户）近 30 日挂牌量 vs 挂牌折价
本次新增子模型：监控上游核心供货商的失信风险，以及上游商家大规模抛货带来的采购踩坑风险，给采购决策增加一层上游风险提示。
供货集中度 × 风险敞口
华鑫钢贸占螺纹钢采购量 23.6%，在手未交付订单 1,860 万元，同时出现失信被执行与账户冻结 → 断货与预付款损失风险高，建议立即启动备源（中天钢铁有承接余量）。

大模型选型与演进策略

先 RAG 快速落地，沉淀足量案例后再微调
阶段一 · RAG 知识库 + Prompt 工程 当前
通用大模型 + 私有向量库检索增强 + 结构化提示词模板，快速上线、零训练成本，业务闭环优先。
阶段二 · 首次 LoRA 小参数微调 二期
沉淀足量自有业务案例 + 平台行业市场案例（目标 ≥3,000 条，当前 3,186 条已达标）后执行，让模型适配本商圈市场特征与公司经营风格。
阶段三 · 周期性迭代 长期
知识库实时检索更新 + 周期性 LoRA 微调；高频判断失误场景优先纳入微调数据集。
不要一开始就直接训练专属大模型 —— 优先 RAG + 提示词工程快速落地，先跑通业务闭环，沉淀真实业务案例之后再微调，投入产出比最高。
